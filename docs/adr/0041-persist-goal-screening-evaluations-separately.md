# Persist Goal screening evaluations separately

Goal relevance is evaluated independently for each Chat–Goal pair with a continuous `0..1` score and an initial admission threshold of `0.7`; missing or invalid scores fail closed. Every decision must remain available for calibration and error analysis. Persist structured screening records in a separate local append-only JSONL dataset rather than Goal History or the bounded runtime diagnostics. Each record includes the complete normalized screening input snapshot (Chat Summary, Goal title, Goal description, and current Goal Summary) plus fingerprints, while excluding raw message batches, credentials, and unrelated Contexts. Operational logs retain only a reference and outcome summary so unrelated screening activity cannot pollute the Goal feed and transient diagnostics cannot erase the evaluation sample.
